03 / Behaviour summary

Virus

Attaches to a host file or program and may spread when the host is shared or executed. Use updated security software and handle attachments carefully.

Worm

Can propagate independently across vulnerable systems. Patching, firewalls, monitoring and network segmentation reduce risk.

Trojan

Uses deception to appear legitimate. Install software from trusted sources and review requested permissions.
